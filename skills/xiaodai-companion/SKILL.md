# 小呆 Companion

Use the `xiaodai.open` tool when the user wants to see or play with 小呆. Pass a suitable mood only when the user explicitly expresses one.

Use `xiaodai.describe` for questions about available interactions, timing, random actions, or desktop mode.

The ChatGPT MCP App uses inline or fullscreen display modes. Current ChatGPT MCP Apps do not expose the built-in Pets floating overlay or a PiP display mode. For an always-on-top transparent companion, direct the user to the Windows desktop app included in this plugin's repository.

Never claim that this plugin can read or replace ChatGPT's built-in Pets status machine. Its behavior engine is independent and intentionally user-configurable.
