# 走跑銜接試作

這兩張圖是小呆走路與跑步落腳姿勢之間的候選影格，已接入開發分支供測試，尚未發布為穩定版。
`comparison.png` 依序呈現現有走路落腳、兩個候選姿勢、現有跑步落地。
PNG 保留生成來源，WebP 使用與跑步素材相同的畫布與色彩標準處理。
`preview.gif` 僅依序循環候選圖，方便檢查姿勢差異；它沒有模擬程式實際的速度或淡化效果。
`compare.html` 提供並排預覽，使用目前播放程式的合成方式和 68 毫秒淡化；其動作時序是示意，並非實際走跑循環。

目前身體高度逐步降低，但第一張候選圖的腳掌與尾巴相對走路落腳姿勢仍有位移；
須先以實際播放檢查落腳滑動、重影與切換節奏，再決定是否採用。
背景測試涵蓋加速、減速、切換中放開與反向；實際桌面上的自然度與重影仍待使用者確認。
