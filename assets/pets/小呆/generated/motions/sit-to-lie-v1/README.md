# 小呆坐下／趴下過渡 v1

這組影格把已核可的寫實坐姿與趴姿接在一起。執行時正向播放為坐下到趴下，反向播放為起身回到坐姿。

## 影格

- `../sit-idle-v1/frames/frame-000-neutral.png`：核可坐姿端點
- `frames/frame-010-lean-forward.png`：仍坐在後腿上，前腳前移、肩膀開始下降
- `frames/frame-020-chest-lowered.png`：胸口接近地面、後腿逐步收進趴姿
- `../lie-idle-v1/frames/frame-000-neutral.png`：核可趴姿端點

## 生成方式

使用內建 ImageGen，以核可的 `identity-sit-v1.png` 與 `identity-lie-v1.png` 同時作為身分與姿勢端點參考。要求保留小呆的淡橘虎斑、奶油色胸口、綠褐色眼睛、粉紅鼻、耳朵與身形比例，並輸出真正透明背景的寫實全身素材。

每張中間圖都分別指定解剖上合理的重心：第一張只下降約 15–20%，第二張讓胸口接近地面。避免卡通、3D、額外肢體、道具、文字、裁切與誇張動作。

注意：兩個端點的原始長寬比不同，因此執行時採底部對齊並使用 170 ms 交叉淡化。後續若要達到最終發行品質，可再補一張「肘部接觸地面」影格，並統一所有素材畫布尺寸。
